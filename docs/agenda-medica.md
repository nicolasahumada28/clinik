# Agenda medica

La agenda actual se modela mediante `Cita`, paciente, profesional, fecha/hora, tipo, estado, asistencia, cancelacion y notas.

Estados iniciales: `PROGRAMADA`, `COMPLETADA`, `CANCELADA`, `NO_ASISTIO` y `REPROGRAMADA`. La integracion FullCalendar y las vistas dia/semana/mes/timeline quedan para la capa Thymeleaf del MVP web.
