# API REST

Base: `/api/v1`.

## Recursos principales

- `GET|POST /pacientes`, `GET /pacientes/{id}`
- `GET|POST /profesionales`, `GET /profesionales/{id}`
- `GET|POST /citas`, `PUT /citas/{id}/cancelar`, `POST /citas/{id}/asistencia`
- `GET|POST /ordenes-medicas`
- `GET|POST /examenes`, `/examenes/{id}/documentos`
- `GET|POST /deudas`, `GET|POST /pagos`
- `POST /auth/login`

Swagger UI: `http://localhost:8080/swagger-ui.html`.
